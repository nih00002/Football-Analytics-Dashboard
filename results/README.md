# Dashboard Results

This folder contains selected screenshots from the interactive football analytics dashboard developed as part of a CS560 course assignment completed in Fall 2, 2024.

The screenshots were extracted from the original submitted project outputs and are included here for portfolio presentation.

## Selected Visualizations

- `dashboard_overview.png` — Overall interactive dashboard interface
- `cap_cash_by_position.png` — Cap Value and Cash Spent distribution by player position
- `team_cap_cash_comparison.png` — Team-level Cap Value and Cash Spent comparison
- `player_efficiency_across_teams.png` — Player efficiency visualization across teams
- `top_10_players_by_cap_value.png` — Top 10 players ranked by Cap Value
- `top_10_players_touchdowns_table.png` — Top 10 players by touchdowns presented as a table
